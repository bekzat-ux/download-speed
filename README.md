# download-speed

Консольный скрипт на Node.js, который измеряет скорость скачивания по заданному адресу.

Что делает:

1. Принимает URL (например, ссылку на тяжёлую картинку).
2. Делает к нему **10 запросов последовательно** — каждый следующий начинается только после полного получения ответа на предыдущий.
3. Считает **среднее время запроса** и **общий объём** скачанных данных.
4. Печатает **скорость скачивания**.

## Требования

- Node.js **18 или новее** (используется встроенный `fetch`)
- Внешних зависимостей нет, `npm install` не нужен

Проверить версию: `node --version`

## Запуск

```bash
git clone <ссылка-на-ваш-репозиторий>
cd download-speed
node index.js <url>
```

Пример:

```bash
node index.js https://avatarko.ru/img/kartinka/1/Crazy_Frog.jpg
```

Или через npm:

```bash
npm start -- https://avatarko.ru/img/kartinka/1/Crazy_Frog.jpg
```

## Пример вывода

```
Адрес: http://localhost:8080/
Запросов: 10 (последовательно)

# 1: 5.243 МБ за 12 мс
...
#10: 5.243 МБ за 5 мс

--- Итоги ---
Успешных запросов:    10 из 10
Среднее время:        6 мс
Скачано всего:        52.429 МБ (52428800 байт)
Скорость скачивания:  ... МБ/с (... Мбит/с)
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Время запроса | миллисекунды (мс) |
| Объём данных | мегабайты (МБ), 1 МБ = 1 000 000 байт (также выводится точное число байт) |
| Скорость | **МБ/с** (мегабайты в секунду) и **Мбит/с** (мегабиты в секунду, 1 байт = 8 бит) |

Скорость считается как `общий объём / суммарное время всех успешных запросов`.
Время каждого запроса измеряется от отправки запроса до полного получения тела ответа.

## Обработка ошибок

- Если запрос завершился ошибкой (сеть, HTTP-статус не 2xx), это выводится в консоль, а скрипт продолжает со следующим запросом. В итогах учитываются только успешные запросы.
- Если не удалось ни одного запроса, скрипт завершается с кодом `1`.
- Некорректный URL или отсутствие аргумента — сообщение об ошибке и код `1`.

## Примечание

К запросам добавлен заголовок `Cache-Control: no-cache`, но CDN и прокси всё равно могут отдавать файл из кэша — тогда скорость будет выше, чем «с оригинального сервера».
